#📌 Projektbeschreibung

Dieses Projekt zeigt eine moderne Umsetzung eines Sticky Headers, der sich während des Scrollens dynamisch verändert.
Beim Herunterscrollen ⬇️:
 • Verkleinert sich das Logo 🖼️
 • Der Navigationsbereich erhält einen dunklen Hintergrund 🌑
 • Die Textlinks werden heller ✨

Beim Zurückscrollen nach oben ⬆️ wird alles wieder in den ursprünglichen Zustand zurückgesetzt.
Die Animation basiert auf JavaScript + CSS Transition und eignet sich perfekt zum Lernen und für reale Webprojekte.

 • ⚡ Verwendung dynamischer CSS-Klassen

#📌 About the Project

This project presents a clean and modern Sticky Header that animates when the user scrolls.
When scrolling down ⬇️:
 • The logo smoothly shrinks 🖼️
 • The navbar background becomes darker 🌑
 • The link colors turn brighter ✨

When scrolling back to the top ⬆️, everything returns to its original state.
Built using JavaScript + CSS Transitions, this project is perfect for learning, practicing, or integrating into real websites.

⸻

#✨ Features
 • 🌀 Smooth logo resize animation
 • 🎨 Dynamic background & text color transitions
 • ⚡ Class-based styling controlled via JavaScript
 • 📱 Lightweight, clean and extensible
 • 🎓 Ideal for DOM and CSS animation practice
